# eshkere

## Стример-мод

В **Опции → Стример-мод** переключатель управляет захватом слоя оверлея:

- **Вкл** — оверлей допускается в скриншоты и запись всего экрана. Это значение
  по умолчанию: так же оверлей работал до появления переключателя.
- **Выкл** — оверлей просит SurfaceFlinger исключить его из захвата. Это не
  гарантия приватности: приложение записи или прошивка могут вести себя иначе.

Режим меняется без перезапуска. Он сохраняется при создании или обновлении
конфига; старые конфиги сохраняют прежний режим «вкл». При ошибке переключения
состояние возвращается назад и появляется сообщение.

В записи выбирай **весь экран**, а не одно приложение: системный захват одного
приложения может исключить независимый слой оверлея. Режим меняет только слой
оверея, не снимает защиту с игры или других приложений. Доступность захвата
зависит от Android, прошивки и программы записи; универсальная работа на всех
устройствах не гарантируется. Сборка проекта — arm64, создание слоя поддерживает
Android 8 и новее.

Для проверки на устройстве: открой меню/ESP, включи режим, сделай системный
скриншот и короткую запись **всего экрана**; повтори с режимом «выкл», затем
снова включи и проверь результат после поворота экрана. Если прошивка или
запись не учитывают флаг, результат может отличаться.
