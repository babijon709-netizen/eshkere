# Control API — шаг 1

Сейчас здесь только проверка доступности сервера. Это не сам чит и пока не переключает его.

## Локальная проверка

```sh
cd server
npm start
```

Откройте `http://localhost:3000/healthz`. Ожидаемый ответ:

```json
{"ok":true}
```

Render будет запускать сервис командой `npm start` и проверять путь `/healthz`.

Следующий небольшой шаг — добавить защищённый административный переключатель. После него отдельно добавим подсчёт активных запусков, а подключение клиента сделаем только после проверки API.
